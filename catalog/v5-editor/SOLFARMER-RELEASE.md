# SolFarmer · solfarmer-demo-20261113a

Дата: 13.11.2026. Основа: 9d77140ae41d42d5193e65a982c8969b93e729b9.

Отдельный проект `solfarmer-official-demo` создан глубоким копированием DEMO-схемы Mining Blocks. Исходные записи, пользовательские конфигурации и JSON не заменяются. Прямая карточка: `detail.html?project=solfarmer-official-demo`.
Редактор: `editor.html?project=solfarmer-official-demo&view=detail`.

Пользовательские числовые показатели, оценки и обещания выплат не добавлены. Галерея использует повтор официальной иллюстрации для сохранения полного шаблона, а не скриншоты аккаунта.

Изменения ограничены `/catalog/v5-editor/`. `/catalog/v5/`, `/catalog/v4.2/` и прочие папки не изменялись.
