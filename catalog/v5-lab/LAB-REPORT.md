# Визуальная лаборатория V5 — этап 1

Дата проверки: 09.11.2026 (Таллинн).
Исходная V5: commit `b033dcd65592efa8fbdb6c99d08251925e265da4`.

## Изоляция

Самостоятельная копия `/catalog/v5/` находится в `/catalog/v5-lab/`, со всеми 38 исходными файлами, включая локальные изображения и Nocid. Исходные V5, V4.2 и catalog-lab не изменены. Публикация лаборатории и её дальнейших исправлений разрешена владельцем; действующая V5 не меняется.

Ресурсы и переходы используют относительные пути внутри лаборатории. Manifest имеет относительные start_url и scope; название приложения отдельно. Ключи браузерного хранилища — `zz-v5-lab-shared`, `zz-v5-lab-theme`, `zz-v5-lab-catalog`, `zz-v5-lab-layout-desktop-v1`. Сообщения между каталогом и iframe имеют отдельный префикс `v5-lab:`.

## Как открыть

1. Получить ветку лаборатории на ПК.
2. В корне репозитория запустить `python -m http.server 8000 --bind 127.0.0.1` (в Windows можно `py -m http.server 8000 --bind 127.0.0.1`).
3. Открыть `http://127.0.0.1:8000/catalog/v5-lab/` и нажать «Редактор ПК · в этом браузере».
4. Прямая ссылка HashGarden: `http://127.0.0.1:8000/catalog/v5-lab/detail.html?project=hashgarden-demo&editor=1`.
5. Nocid: `http://127.0.0.1:8000/catalog/v5-lab/detail.html?project=nocid&editor=1`.

Нужна ширина окна от 1001 px. В редакторе проект можно менять через список. Перед сменой проекта нужно сохранить изменения. Текущие настройки общие для проектов.

На GitHub Pages редактор доступен в режиме локальных настроек браузера по специальной ссылке:
`https://zetta-zone.github.io/catalog/v5-lab/?editor=1`.
В каталоге нужно нажать «Редактор ПК · в этом браузере». Прямой вход:
`https://zetta-zone.github.io/catalog/v5-lab/detail.html?project=hashgarden-demo&editor=1`.

Обычные посетители по основному адресу не видят кнопок редактирования. Параметр `editor=1` — явный вход в инструмент локальной компоновки, а не пароль или авторизация владельца. Любой открывший специальную ссылку может изменить только собственный просмотр; настроить публичные данные, записать файлы или отправить изменения в GitHub невозможно. API записи, токенов и серверных административных функций нет. При ширине меньше 1001 px показывается пояснение; редактор ПК не запускается.

## Поддерживаемые блоки

Верх карточки: название/логотип/описание/платформы единым блоком; избранное; статистика; галерея с подписями и миниатюрами; слоган; заголовок; особенности; оценки; статус проверки; краткие условия; регистрация/сравнение; примечание к регистрации; уведомление проекта.

Разделы: обзор, возможности, механика, финансы, плюсы/минусы, проверка, итог.

Всего 20 стабильных слотов. Два служебных слота могут быть скрыты, если у проекта нет соответствующего текста. Крестик, верхняя служебная панель, меню разделов, боковая справка и нижняя мобильная панель не редактируются.

## Управление

Выбор кликом на блоке или в списке. Границы блоков, выбранный блок и цель перетаскивания подсвечиваются; сетка показывает 12 колонок.

Перетаскивание: центр целевого блока — обмен; верхняя/нижняя пятая часть — вставка в строку; левая/правая пятая часть — разделение места по колонкам. Для точного размещения есть номер строки, колонка, ширина/высота в ячейках, ширина в процентах, минимальная высота, внутренний отступ, горизонтальное и вертикальное выравнивание, общий промежуток. Свободное смещение X/Y ограничено ±8 px при промежутке не меньше 18 px. Пересечения сетки отклоняются; при ручном перемещении занятые места освобождаются переносом конфликтующих блоков в последующие строки.

Размеры основаны на CSS Grid, не на абсолютных координатах. Единый контракт расположения находится в `layout-editor.js` и `layout-editor.css`; он действует для обычного просмотра ПК, а режим чтения раздела использует существующую компоновку. Существующие стили компонентов сохраняют оформление проектов. Перемещение крестика из старых обработчиков исключено; отдельный контроллер закрепляет его с учётом safe-area, сохраняя существующий класс оформления.

## Сохранение

«Сохранить» записывает конфигурацию в localStorage только текущего origin/браузера. После перезагрузки она валидируется и применяется. Ошибка записи показывается пользователю. Отмена/повтор — до 100 шагов в текущем сеансе. Есть возврат одного блока и всей компоновки; восстановленный вариант также нужно сохранить.

JSON содержит версию схемы, промежуток и геометрию стабильных ID блоков, без данных проекта. Экспорт скачивает файл; импорт доступен через файл и через текст. Проверяются схема, состав блоков, зоны, диапазоны, целые номера ячеек, допустимые выравнивания и пересечения. JSON не исполняется как код. Повреждённые сохранённые данные игнорируются с возвратом к исходной конфигурации. Перенос в действующую V5 автоматически не выполняется.

## Проверки

В Chrome проверены:
- открытие HashGarden и Nocid и переключение проектов;
- сохранение индивидуальных цветов, логотипа Nocid и изображений/заглушек галереи;
- реальное перетаскивание мышью с обменом слогана и заголовка;
- обмен через панель, отмена/повтор, восстановление исходной компоновки;
- изменение отступа, сохранение, перезагрузка и повторное получение сохранённого значения;
- свободное смещение X и отмена;
- импорт корректного JSON через текст и отклонение неверной схемы;
- выход из редактора и переключение слайда Nocid.

Файловый диалог импорта и фактическое скачивание экспортного файла отдельно в браузере не проверялись. Мобильное устройство и safe-area на реальном iPhone не проверялись.

Дополнительно: синтаксис всех JS, наличие HTML-ресурсов, отсутствие исходных ключей хранилища, 12 проверок валидатора (`node catalog/v5-lab/layout-validation.test.cjs`). Проверено отсутствие изменений исходных каталогов.

## Ограничения

- Только подробная карточка ПК, от 1001 px; остальные восемь представлений не разрабатывались.
- Две отдельные зоны: верх карточки и разделы. Между зонами перенос не реализован.
- Составные блоки перемещаются целиком; логотип, платформы и текст внутри identity отдельно не перемещаются.
- Сетка допускает 100 начальных строк и до 12 строк высоты блока. Неограниченного свободного холста нет.
- Перестановка визуальная: DOM-порядок чтения с клавиатуры не меняется.
- При очень узких колонках содержимое может быть неудобным: владелец должен проверить выбранную ширину. Редактор предотвращает пересечения ячеек, но не оценивает художественное качество компоновки.
- Настройки локальные, не синхронизируются между устройствами. Новая карточка, адрес проекта, загрузка данных обозначены как следующий этап, без автоимпорта.
